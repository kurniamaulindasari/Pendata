Jawab#

Analisis Data Kesuburan Tanah Menggunakan Orange#

File digunakan untuk membaca dataset kesuburan tanah ke dalam Orange. Data yang dimuat berisi atribut kimia dan fisik tanah serta label kelas, yaitu Subur dan Tidak Subur. Output dari ini diteruskan ke tahap preprocessing.

Impute dipakai untuk mengatasi missing value pada dataset. Nilai kosong harus ditangani terlebih dahulu agar proses klasifikasi dapat berjalan dengan baik. Pada atribut numerik, nilai kosong umumnya diganti dengan rata-rata, sedangkan pada atribut kategorik diganti dengan nilai yang paling sering muncul.

Select Columns digunakan untuk mengatur peran setiap atribut. kolom-kolom sifat tanah dijadikan fitur, sedangkan kolom Label dijadikan target klasifikasi. Langkah ini penting agar mengetahui variabel mana yang digunakan sebagai input dan mana yang menjadi hasil prediksi.

Continuize dipakai untuk mengubah atribut kategorik menjadi representasi numerik. diperlukan karena algoritma kNN menghitung kedekatan antar data menggunakan jarak, sehingga seluruh fitur sebaiknya berada dalam bentuk numerik. Pada atribut seperti Tekstur Tanah diubah menjadi variabel numerik agar dapat diproses oleh model.

kNN digunakan untuk membangun model klasifikasi berdasarkan konsep kedekatan antar data. Setiap data baru akan dibandingkan dengan sejumlah tetangga terdekat, lalu kelas ditentukan dari mayoritas tetangga tersebut. Model ini sesuai digunakan setelah data diubah ke bentuk numerik.

Data diproses (impute, seleksi fitur, konversi tekstur ke numerik), lalu diklasifikasi dengan KNN (K=5, Euclidean distance). Evaluasi dengan Test and Score dibawah ini menghasilkan metrik akurasi, presisi, recall, dan F1-score yang menunjukkan model berhasil membedakan tanah subur vs tidak subur.

Test and Score digunakan untuk menilai seberapa baik model kNN bekerja pada dataset. biasanya dilakukan dengan metode cross validation agar hasil lebih objektif. Output ini berupa nilai metrik seperti akurasi, precision, recall, dan F1-score yang digunakan untuk melihat kualitas model klasifikasi.
